
# GeoPulse AI — Build Plan

A premium AI intelligence platform with live-feeling news, AI impact analysis, an interactive 3D globe, and a personalized dashboard. Built directly from the brief (Apple/Bloomberg/Linear aesthetic, #1978E5 primary, Inter, light theme, 8px radius, glassmorphism, Framer Motion).

## Scope (first pass)

- Frontend + Lovable Cloud (auth + DB) + Lovable AI (Gemini 3 Flash) for generated events & impact analysis
- All "news" is synthetic-but-plausible, generated by AI and cached in DB
- Full 3D globe via `react-globe.gl`

## Pages / Routes

```text
/                    Hero landing (animated globe bg, headline, ticker, floating cards, CTAs)
/feed                Global Live Intelligence Feed (cards, filters, sentiment, expand)
/globe               Interactive 3D world map (country pulses, click → side panel)
/event/$id           Event detail: What/Why/Who/Industries/Markets/Timeline/Confidence
/dashboard           Personalized dashboard (interests, widgets, alerts) — auth required
/social              Social Intelligence (viral trends, sentiment spikes) — mocked AI
/login, /signup      Email auth via Lovable Cloud
```

Each route gets its own `head()` metadata. Shared header (blur-on-scroll), footer, and command-palette (⌘K).

## Backend (Lovable Cloud)

Tables:
- `profiles` (id, display_name, created_at)
- `user_interests` (user_id, topic) — Economy, AI, Crypto, Politics, Defense, etc.
- `events` (id, headline, summary, sentiment, risk_score, confidence, countries[], industries[], sources[], category, created_at)
- `event_impacts` (event_id, country_code, impact_score, narrative)
- `event_predictions` (event_id, horizon, prediction, confidence)
- `votes` (user_id, event_id, value) — like/dislike for community trust
- `saved_events` (user_id, event_id)

RLS: public read for `events/event_impacts/event_predictions`; per-user write on `votes`, `saved_events`, `user_interests`, `profiles`. Roles stored separately if added later.

Server functions (`src/lib/*.functions.ts`):
- `generateEvents` — AI generates batch of 8–12 structured events (Output.object with Zod), upserts into DB. Called by cron-style refresh + manual refresh button.
- `analyzeEvent` — Given an event id, AI produces deeper impact narrative + per-country impacts + timeline predictions.
- `personalFeed` — Returns events filtered/ranked by current user's `user_interests`.
- `chatWithIntel` — Streaming chat ("Ask GeoPulse") that answers questions about current events; uses recent events as context.

Server route:
- `src/routes/api/chat.ts` — streaming endpoint for the intel chat assistant.

All AI calls go through `createLovableAiGatewayProvider` in `src/lib/ai-gateway.server.ts` using `LOVABLE_API_KEY` and model `google/gemini-3-flash-preview`. Structured output via AI SDK `Output.object` + Zod.

## Animation system

Framer Motion across the app:
- Hero: character-reveal headline, floating cards with mouse parallax, infinite-scroll ticker, animated grid background (CSS + canvas particles)
- Feed: fade+slide-up cards, shimmer skeletons, breaking-news pulse
- Globe: auto-rotate, country pulse rings on event markers, animated arcs for trade-flow impacts
- Microinteractions: button lift, card elevate-on-hover, blur-on-scroll nav, count-up numbers (`useMotionValue`)
- Page transitions: fade + slight slide via Framer AnimatePresence
- Respect `prefers-reduced-motion`
